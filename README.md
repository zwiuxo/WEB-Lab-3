## ⚙️ Как запустить проект
1. Склонировать репозиторий:
```bash
git clone https://github.com
cd WEB-Lab-3
```
2. Запустить контейнеры:
```bash
docker-compose up -d --build
```
3. Открыть главную страницу: http://localhost:8080/index.php

## 📌 Что сделано
- Данные формы теперь обрабатываются через `process.php`.
- Реализовано сохранение данных в **сессии** и в текстовый файл `data.txt`.
- Создана страница `view.php` для чтения истории заказов из файла.
- Добавлена серверная проверка: если имя не введено, выводится ошибка.
